# Bank Management System

## About the Project
The Bank Management System is a simple web-based application developed using Python, Flask, MySQL, HTML, and CSS.

It helps an administrator manage customers, bank accounts, and transactions through a web interface.

## Features
- Admin Login
- Dashboard with basic statistics
- Add, View, Edit, and Delete Customers
- Create and Manage Bank Accounts
- Deposit and Withdrawal Transactions
- View Transaction History
- Basic Analytics

## Technologies Used
- Python
- Flask
- MySQL / MariaDB
- HTML
- CSS

## Installation and Setup

1. Install Python and MySQL or XAMPP.
2. Clone or download this project.
3. Open the project folder in VS Code.
4. Install the required Python libraries:

   ```bash
   pip install -r requirements.txt
   ```

5. Import `database.sql` into phpMyAdmin to set up the database.
6. Check the database connection settings in `database.py`.
7. Run the application:

   ```bash
   python app.py
   ```

8. Open `http://127.0.0.1:5000` in your browser.

## Note
This project is intended for learning and demonstration purposes. It is not designed for real banking operations.
